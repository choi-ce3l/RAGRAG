# 화면(출력) 구조 — 뼈대

오늘 단계에서 만든 것은 **영역 제목 + 배치 + 자리표시자(placeholder)** 뿐이다.
계산·분류·저장 등 실제 기능 로직은 들어있지 않다. 기능은 이후에 하나씩 추가한다.

## 전제
요구사항.md에 별도 "화면 구조" 절이 없고 실행 환경이 Claude Code(터미널)로 확정돼 있어,
- **영역** = 터미널 출력 블록
- **상태** = 요구사항.md의 예외 스펙
으로 매핑했다.

| 파일 | 대상 | 내용 |

| `B_평가리포트_화면.md` | 기능 2 (평가 파이프라인) | 출력 영역 7개의 제목·순서·자리표시자 |

| `D_표기규칙.md` | 공통 | 파이프라인 상태 기호 · 근거 좌표 포맷 (확정) |

## 배치 확인 방법
```
python scripts/preview_layout.py            # 기능1 + 기능2 정상 상태
python scripts/preview_layout.py --all      # 모든 상태 변형까지
```

## 구현 현황 (2026-08-26)

### 기능 1 — QA 에이전트 (API 키 미사용)
```
python scripts/ask.py "삼성전자의 2024년 연결 무형자산은?"
```
| 단계 | 구현 |
|---|---|
| [01] 온톨로지 매핑 | `numqa.parse_intent` + 개념/업종/필드/문서구조 온톨로지 |
| [02] 검색 | `FactStore` · `LabelStore` · `StructFacts` + 좌표 변환 |
| [03] 계산/추론 | Decimal 조회·증감률·순위·집계 (무-LLM) |
| [04] 도메인 검증 | XBRL 규칙 4~5개 / 비-XBRL 규칙 3개 |
| [05] 답변 생성 | 화면 [1]~[7] 조립 + PII 마스킹 |

상태: S0 정상 · S1 데이터없음 · S2 검증미흡 · S3 모호(되물음) · S6 미지원

### 기능 2 — 평가 파이프라인
```
python evaluation/evaluate.py --dataset <경로>
```
원본 `scripts/evaluate.py`는 건드리지 않았다. 실구현은 `evaluation/`.
