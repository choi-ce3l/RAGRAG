# 기능 1 — 질문 QA 에이전트 출력 화면 (뼈대)

트리거: 사용자가 자연어로 질문 → 자동 인식 (커맨드 없음)

## 영역 배치 (위 → 아래 순서)

```
┌──────────────────────────────────────────────┐
│ [1] 질문 확인                                 │
├──────────────────────────────────────────────┤
│ [2] 파이프라인 진행 (01 → 05)                 │
├──────────────────────────────────────────────┤
│ [3] 답변                                      │  ← 주 영역
├──────────────────────────────────────────────┤
│ [4] 계산 과정                                 │
├──────────────────────────────────────────────┤
│ [5] 근거 출처 (좌표)                          │
├──────────────────────────────────────────────┤
│ [6] 검증 상태                                 │
├──────────────────────────────────────────────┤
│ [7] 알림 / 경고                               │  ← 해당 시에만 표시
└──────────────────────────────────────────────┘
```

---

## [1] 질문 확인
사용자 질문을 그대로 되짚어 무엇에 답하는지 고정한다.

```
❓ 질문: {{사용자 질문 원문}}
   대상 기업: {{기업명}} | 기간: {{기간}} | 개념: {{재무 개념}}
```
> 기업/기간/개념 자리는 01 온톨로지 매핑 에이전트가 채운다. (기능 미구현)

---

## [2] 파이프라인 진행 (01 → 05)
5개 서브에이전트가 순차로 도는 과정을 드러내는 영역.

```
🔗 파이프라인
   ✅ [01] 온톨로지/개념 매핑
   ✅ [02] 검색(RAG)
   ♻️ [03] 계산/추론          재시도 {{n}}/2
   🔄 [04] 도메인 전문가 검증
   ⏳ [05] 답변 생성
```
> 상태 기호 확정: ⏳대기 · 🔄진행중 · ✅완료 · ♻️재시도 · ❌실패 · ⏭️건너뜀
> 기호는 줄 맨 앞, 점선 리더 없음. 정의는 `D_표기규칙.md` 참고.

---

## [3] 답변
```
💬 답변
{{자연어 답변 본문}}
```

---

## [4] 계산 과정
```
🧮 계산 과정
   {{단계 1}}
   {{단계 2}}
   ─────────────
   {{결과}}
```
> 계산 로직 없음. 수식/단계가 들어갈 자리만 잡아둔 것.

---

## [5] 근거 출처 (좌표)
```
📎 근거
   [1] {{corp_name}} · {{report_nm}}{{정정플래그}}
       {{section_path}}   [표 {{t}}]
       rcept {{rcept_no}} · {{chunk_id}}

   [2] {{...}}
```
> 좌표 포맷 확정: 3줄 1블록 (기업·문서 / 섹션경로·표 / 접수번호·청크).
> 플래그 ⚠️정정 · ⛔대체됨 · 🚫제외. 필드 매핑은 `D_표기규칙.md` 참고.
> 답변 본문([3])에서는 `[1]` 번호만 쓰고 전체 좌표는 이 영역에서만 편다.

---

## [6] 검증 상태
```
{{상태 아이콘}} 검증 상태: {{검증완료 | 검증 미흡}}
   확인 항목: {{단위 일치}} / {{기간 정합성}} / {{부호·방향}}
```
> 04 도메인 전문가 에이전트의 체크리스트 자리. 규칙 미구현.

---

## [7] 알림 / 경고
해당하는 경우에만 나타나는 영역. (상태별 표시는 `C_상태별_변형.md` 참고)

```
⚠️ {{경고 메시지}}
🔒 {{개인정보 마스킹 안내}}
🚫 {{인젝션 감지로 제외된 문서}}
```
