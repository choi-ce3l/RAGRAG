## [2] 요약 지표
```
📊 요약
   행동 정확도 .............. {{ %}}  ({{n}}/{{전체}})   ← 전 문항
      부분 일치 ............. {{ %}}

   최종 답변 정확도 ......... {{ %}}  ({{맞음}}/{{채점가능}})
   근거 좌표 정확도 ......... {{ %}}
   검증 통과율 .............. {{ %}}
```
> 두 축은 독립이다. **행동 정확도**는 "답했어야 했는가"를 전 문항에서,
> **답변 정확도**는 "무엇을 답했는가"를 수치 비교가 가능한 문항에서 잰다.
> 행동 축이 없으면 채점 가능 문항이 전체의 37%뿐이라 개선을 측정할 수 없다.
> 정의는 `D_표기규칙.md` 3절 참고.

   ▼ 오답·실패 상세 ({{n}}건)

        근거 : rcept {{rcept_no}} {{아이콘}}

> `정확`·`근거`·`검증` 컬럼은 셀당 이모지 1개만 (폭 2칸 고정, 세로선 정렬 유지).
