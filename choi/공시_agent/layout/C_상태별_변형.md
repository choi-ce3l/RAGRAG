# 상태별 화면 변형 (뼈대)

요구사항.md의 예외 스펙을 상태로 정리한 것. 각 상태에서 **어떤 영역이 나타나고 사라지는지**만
정의한다. 상태를 판정하는 분류 로직은 아직 없다.

---

## 기능 1 — QA 에이전트 상태

| 상태 | 트리거 | 표시되는 영역 | 비고 |
|---|---|---|---|
| `S0` 정상 | 근거 확보 + 검증 통과 | [1][2][3][4][5][6] | 기본 |
| `S1` 데이터 없음 | corpus에서 관련 자료 못 찾음 | [1][2] + 전용 블록 | [3][4][5][6] 숨김 |
| `S2` 검증 미흡 | 재시도 후에도 04 검증 실패 | [1][2][3][4][5][6][7] | [7]에 경고 |
| `S3` 질문 모호 | 기업/기간이 여러 개로 해석됨 | [1] + 전용 블록 | 파이프라인 중단, 되물음 |
| `S4` 인젝션 감지 | corpus 텍스트에 지시문 패턴 | S0 + [7] | 해당 근거만 [5]에서 제외 |
| `S5` 개인정보 포함 | 주민번호/연락처 등 | S0 + [7] | [3][5] 본문이 마스킹된 형태 |
| `S6` 미지원 경로 | narrative 질문 (comparison/existence intent) | [1][2] + 전용 블록 | **구현 단계 한정** — narrative 경로가 붙으면 사라짐 |

> S4·S5는 다른 상태와 겹칠 수 있음 (예: S2 + S5).
> S6은 요구사항의 예외 스펙이 아니라 **구현이 아직 안 붙은 구간을 정직하게 알리는 임시 상태**다.

### S1 — 데이터 없음 전용 블록
```
🔎 관련 공시/데이터를 찾을 수 없습니다.

   시도한 검색 범위
     기업   : {{검색한 기업}}
     기간   : {{검색한 기간}}
     문서   : {{검색한 문서 종류}}
     쿼리   : {{사용한 검색어}}
```
> 답변을 지어내지 않는다.

### S2 — 검증 미흡 경고 블록
```
⚠️ 검증 미흡 — 신뢰도가 낮을 수 있음
   재시도 {{n}}/2 회 후에도 다음 항목이 확인되지 않았습니다:
     - {{미확인 항목}}
```

### S3 — 명확화 되물음 블록
```
❔ 질문을 좀 더 좁혀주세요.

   {{모호한 부분}}에 해당하는 후보:
     1) {{후보 1}}
     2) {{후보 2}}
```
> 추측하지 않는다.

### S4 — 인젝션 감지 블록
```
🚫 다음 문서는 지시문 패턴이 감지되어 근거에서 제외했습니다.
     - {{문서 좌표}} (감지 패턴: {{패턴}})
   나머지 근거로 정상 답변했습니다.
```

### S5 — 마스킹 안내 블록
```
🔒 개인정보가 감지되어 마스킹 처리했습니다. ({{n}}건)
```

### S6 — 미지원 경로 블록 (임시)
```
🚧 이 질문은 서술형(narrative) 경로가 필요합니다 — 아직 붙지 않았습니다.

   판정된 intent: {{comparison | existence}}
   현재 지원 범위: XBRL 수치 질문 (매출액·영업이익·부채비율 등의 조회/증감률)
   다음 단계에서 02 검색 + 05 LLM 답변 생성을 붙이면 답할 수 있습니다.
```
> 답을 지어내지 않고 "아직 못 한다"를 명시한다. S1(데이터 없음)과 구별해야 한다 —
> S1은 데이터가 없는 것이고, S6은 데이터는 있을 수 있으나 경로가 없는 것이다.

## 기능 2 — 평가 파이프라인 상태

| 상태 | 트리거 | 표시되는 영역 | 비고 |
|---|---|---|---|
| `E0` 정상 완료 | 전 문항 실행 성공 | [1][2][3][4][5][6][7] | 기본 |
| `E1` 데이터셋 형식 오류 | 실행 **전** 검증 실패 | [1] + 전용 블록 | 평가를 시작하지 않음 |
| `E2` 문항 에러/타임아웃 | 실행 **중** 특정 문항 실패 | [1] + 전용 블록 | 즉시 중단 |

### E1 — 형식 오류 블록
```
🛑 데이터셋 형식 오류로 평가를 시작하지 않았습니다.

   파일   : {{경로}}
   위치   : {{줄/항목 인덱스}}
   문제   : {{누락 필드 또는 형식 불일치}}
```

### E2 — 문항 실패 블록
```
🛑 평가를 중지했습니다.

   실패 문항 : {{id}} — {{질문}}
   실패 단계 : {{01~05 중}}
   오류      : {{에러 종류 / 타임아웃}}

   원인 확인 후 수정하고 재실행하세요.
```
> 부분 결과를 요약 지표로 내지 않는다.
